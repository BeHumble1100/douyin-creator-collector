# Changelog

## 1.0.0 — First public release

- Packaged the locally used V7.5 userscript as a standalone repository.
- Supported creator-square and creator-profile page detection, movable panel with collapse/expand, locally stored records, CSV export, profile-page links, settlement ranges and unauthorized-state handling.
- Added documentation and offline smoke tests.

The original locally used script identified itself as V7.5. The public release uses semantic version `1.0.0`; storage keys remain unchanged to preserve locally saved records when upgrading on the same site and browser.
